# Rubric — index

> Ground rules (inline by design): never delete knowledge; integrate, don't
> append; max 5 findings/corrections per pass; converged is a valid verdict.

This file is a category index. It routes to one criterion file per concern.
Load only the criterion you are currently judging or fixing against — when
reviewing a whole skill, walk the rows top to bottom, loading one at a time.

| Concern being judged                                             | Load            |
| ------------------------------------------------------------------ | --------------- |
| frontmatter `description` — does the skill trigger when it should? | `triggering.md` |
| file layout, index/router shape, size budgets, rule placement      | `structure.md`  |
| phrasing — imperative, positive voice, explained "why"             | `voice.md`      |
| substance — generality, examples, dead weight, self-consistency    | `content.md`    |

Findings cite the criterion file and rule number (e.g. `structure.md #2`) — or,
when judging against a context document, a context location (`context: "<short
verbatim quote>"`) — so a later correct pass can re-load exactly the rule a fix
must satisfy.
