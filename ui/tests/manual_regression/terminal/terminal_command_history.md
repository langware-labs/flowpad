* validate terminal is visible and ready

* wait for "one" to appear in output

* type "echo two" and press Enter

* wait for "two" to appear in output

* wait for "three" to appear in output

* validate "echo three" is recalled at the prompt

* press Down arrow key

* validate "echo three" is recalled at the prompt

* press Enter to execute the recalled command

* validate "three" appears in the output again
