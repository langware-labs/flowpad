# Flowpad 0.2.277

*Released Nov 19, 2026*

## New
- **Secret manager access** — see the vault's status and open or close access; one holder per instance.
- **Bookmarks panel** — a breadcrumb on top, one level at a time, opening at the project you have open.

## Improved
- An app opens from a link or a tool, not only from a typed address.
- Setup messages say what each thing is and what its button does, with one word per thing throughout.

## Fixed
- A served app's own module imports are no longer refused by the page key.
- The chat list shows a finished turn followed by an away summary as complete, not unknown.
