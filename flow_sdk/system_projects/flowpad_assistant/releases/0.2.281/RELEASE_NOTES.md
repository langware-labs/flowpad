# Flowpad 0.2.281

*Released Nov 23, 2026*

## New
- **Agents show where your message stands** — when you message an agent on Telegram, Slack or WhatsApp, it marks your message with 👀 while it works on the answer and with 👍 once the answer is sent. This also works on channels connected through the Flowpad hub, such as the Flowpad Telegram bot.
