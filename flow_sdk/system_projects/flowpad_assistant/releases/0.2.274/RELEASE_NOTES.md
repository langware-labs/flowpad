# Flowpad 0.2.274

- **Pages run only with a key this machine minted** — a page opened by Flowpad or an agent runs at once; a page opened from an outside link asks first ("Allow", "Always allow this page"). An installed app is allowed silently.
- **Help requests** — a help request and its diagnosis are one card: status, issue, root cause, and Fix / Ask for help / Done; requests route to the right helper.
- **Tags** — Classify on a message opens the tag editor's Try pane and runs it.
- **Charts** — a flowchart format, and sequence and flowchart charts are also written as one HTML file; the side panel tells State and Notes apart.
- **Automations** — a callback automation keeps its session, with a shared link and a "Created through" chip; the job details window links to the automation and its runs.
- **Conversations** — a prompt is sent as a message plus a prompt in two boxes; form answers are an ordinary reply.
- **Contact picker** — your 5 most recent contacts are on top.
- **Stream Inbox** — a conversation is as recent as its newest message.
- **Fixes** — a return to an app that is already up asks the backend nothing.
