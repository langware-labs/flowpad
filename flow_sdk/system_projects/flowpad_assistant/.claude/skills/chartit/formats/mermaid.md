# mermaid — anything Mermaid draws well

A chart type of the chartit skill: read `../SKILL.md` first — it sets the folder, the shared rules and how a
chart is indexed, linked, shown and verified. This file adds only what a `mermaid` chart needs.

The diagram goes in one ```` ```mermaid ```` block in `CHART.md` under the prose.

Use it for a state machine, an ER or class diagram, a gantt. A **decision flow is a `flowchart` chart**
(`flowchart.md`), not a Mermaid one: Mermaid has no notes or hover on a flowchart, its layout cannot be
pinned, and the editor shows only the diagram — details end up inside the flow.
