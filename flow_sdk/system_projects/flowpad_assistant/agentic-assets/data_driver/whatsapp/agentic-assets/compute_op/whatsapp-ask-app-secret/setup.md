1. Open **[developers.facebook.com/apps](https://developers.facebook.com/apps)** and sign in with the Facebook account that will manage the bot.
2. **Create app** → use case **Other** → type **Business** → give it a name → **Create app**.
3. On the app's dashboard, find **WhatsApp** and press **Set up** (accept the terms; a test business account and a free test number are made for you).
4. Go to **App settings → Basic**: the **App ID** is at the top, the **App secret** is behind **Show**.
