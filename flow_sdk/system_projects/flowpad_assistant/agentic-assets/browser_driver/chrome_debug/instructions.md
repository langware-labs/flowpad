# Your browser

This session's browser is **Chrome debug**: Chrome Canary on a fixed debugging port, on a profile of its own. Drive it with the `mcp__chrome_debug__*` tools.
- It has none of the user's sign-ins. When a site needs one, open its sign-in page and hand the user the way in; a sign-in made there is kept.
- The window opens on your first browser call. The user may have DevTools attached to the same window; leave tabs you did not open alone.
