# Your browser

This session's browser is the **Flowpad integrated browser**: Flowpad's own browser window, on a profile of its own. Drive it with the `mcp__agent_browser__*` tools.
- It has none of the user's sign-ins. When a site needs one, open its sign-in page and hand the user the way in; a sign-in made there is kept.
- The window opens on your first browser call and is shared by this Flowpad's sessions.
