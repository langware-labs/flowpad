support-ticket-agent-flow

The help desk flow with two agents and a trust boundary between them. The support agent talks to the user and is untrusted; what it sends inward is screened before the internal agent or the team sees it. The internal agent runs the RCA and steers the support agent. It starts when a user opens a request and ends when the ticket and the internal conversation are closed.
