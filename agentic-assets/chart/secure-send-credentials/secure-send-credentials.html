secure-send-credentials

Proposed design — how a credential's values travel from one conversation member to another without a secret manager. Each device advertises a signed public key into the conversation; the sender's backend seals the values to the receiver's devices; the receiver's backend decrypts and writes them into its own store. Ends with the credential connected on the receiver and the sealed envelope deleted from the hub.
