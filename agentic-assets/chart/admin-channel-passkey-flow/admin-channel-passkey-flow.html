admin-channel-passkey-flow

How a passkey lets a user into a protected machine through the admin channel. The machine is connected to the hub over a websocket it opened itself, holds the user's passkey public key, and checks every approval itself; the hub only relays. An approval opens access for 1 hour. Planned design, not built yet.
